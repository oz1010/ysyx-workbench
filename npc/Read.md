## 外设地址分布

我们先给出ysyxSoC包含的外围设备和相应的地址空间.

| 设备          | 地址空间                  |
| ------------- | ------------------------- |
| CLINT         | `0x0200_0000~0x0200_ffff` |
| SRAM          | `0x0f00_0000~0x0f00_1fff` |
| TEST          | `0x0f00_2000~0x0fff_ffff` |
| UART16550     | `0x1000_0000~0x1000_0fff` |
| SPI master    | `0x1000_1000~0x1000_1fff` |
| GPIO          | `0x1000_2000~0x1000_200f` |
| PS2           | `0x1001_1000~0x1001_1007` |
| MROM          | `0x2000_0000~0x2000_0fff` |
| VGA           | `0x2100_0000~0x211f_ffff` |
| Flash         | `0x3000_0000~0x3fff_ffff` |
| ChipLink MMIO | `0x4000_0000~0x7fff_ffff` |
| PSRAM         | `0x8000_0000~0x9fff_ffff` |
| SDRAM         | `0xa000_0000~0xbfff_ffff` |
| ChipLink MEM  | `0xc000_0000~0xffff_ffff` |
| Reverse       | 其他                      |

SRAM实际可用8K，后面的空间重新规划为TEST空间，用于辅助测试。
- 向0x0f00_2000写入4字节索引，用于初始化flash测试
- 向0x0f00_2004写入4字节索引，用于初始化psram测试

| flash_idx      | 说明                      |
| ------------- | ------------------------- |
| 1             | 初始化FLASH前16字节为0x30+i |
| 2             | 初始化FLASH为char-test代码 |

| psram_idx      | 说明                      |
| ------------- | ------------------------- |
| 1             | 初始化PSRAM前16字节为0x30+i |
